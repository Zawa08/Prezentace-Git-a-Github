# Kódová matrioška: Žákovská knížka

| Část | Soubor    | Funkce         | Branch     |
| ---- | --------- | -------------- | ---------- |
| A1   | znamky.py | prumer         | polovina-a |
| A2   | znamky.py | prospel        | polovina-a |
| B1   | test.py   | body_na_znamku | polovina-b |
| B2   | test.py   | slovne         | polovina-b |

Studenti se rozdělí do čtyřčlenných týmů. Ten se ještě rozdělí do dvojic, každá dvojiced si vytvoří svůj branch. Každý student naprogramuje jednu funkci a potom ji pomocí Gitu pushne. Nakonec se všechny funkce mergnout s main branch a spustí se finalní program v main.py.

Spuštění: `python main.py` Kontrola: `python kontrola.py`
